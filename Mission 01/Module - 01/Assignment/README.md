# TypeScript Problem Solving & OOP Assignment

## Overview

This assignment focuses on practicing TypeScript concepts from Modules 1, 2, and 3 through coding problems and blog writing.

The coding section includes 8 problems covering basic types, optional and default parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and Object-Oriented Programming (OOP).

## Assignment Files

- `solutions.ts` — Contains the solutions to all 8 coding problems.
- `type-vs-interface.md` — Explains the differences between Type Alias and Interface in TypeScript.
- `generics-and-promises.md` — Discusses how Generics work and how they are used with Promises.
